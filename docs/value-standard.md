# N3uralia Value Standard

Este repositorio adopta el estándar transversal de valor N3uralia.

## Cadena obligatoria

`problema -> outcome -> baseline -> intervención -> resultado -> evidencia -> E/L/C -> V0-V7 -> valor atribuible -> benchmark -> pricing readiness`

No considerar una feature material terminada sólo porque funciona técnicamente.

## E/L/C

- **E — Evidence:** E0 sin medición; E1 actividad; E2 decisión humana; E3 outcome operacional con baseline; E4 resultado económico trazable.
- **L — Level:** L1 visibilidad; L2 control; L3 priorización; L4 decisión asistida; L5 resultado operacional.
- **C — Coverage:** cobertura real del proceso/requisitos/datos bajo gestión. No confundir ausencia con cero.

## Valor V0-V7

- V0 habilitador técnico
- V1 visibilidad
- V2 control
- V3 priorización
- V4 decisión asistida
- V5 resultado operacional
- V6 resultado económico
- V7 infraestructura estratégica / memoria institucional

## Evidencia

Usar sólo: DEMOSTRADO, CALCULABLE, ESTIMADO, HIPÓTESIS, NO MEDIBLE AÚN.

Nunca convertir benchmark, capital bajo gestión, riesgo bruto o volumen de datos en ROI.

## Value Ledger mínimo

Registrar por capacidad material:
- fecha y actor;
- problema previo;
- baseline;
- intervención;
- decisión humana;
- resultado observado;
- tiempo/costo antes y después;
- ahorro realizado;
- costo evitado;
- ingreso incremental;
- valor bajo control;
- evidencia;
- nivel E/L/C;
- nivel V;
- siguiente medición.

## Pricing gate

No recomendar precio por valor hasta tener outcome atribuible. Separar:
- piso de costo;
- sustituto de mercado;
- techo de valor;
- implementación;
- mensualidad;
- SLA;
- módulos/expansión.

`valor bajo control` nunca se suma como beneficio.

## Definition of Done

Para una capacidad material, el cierre debe responder:
1. ¿Qué outcome cambia?
2. ¿Cuál era el baseline?
3. ¿Qué evento demuestra uso/intervención?
4. ¿Qué decidió el humano?
5. ¿Qué cambió después?
6. ¿Qué evidencia lo respalda?
7. ¿Qué nivel E/L/C y V alcanzó?
8. ¿Cuál es la siguiente medición que puede elevar confianza o pricing?

Si 1–3 no existen, la capacidad sigue siendo V0/V1 aunque el código esté completo.

## Métricas verticales iniciales — MOTIL / ERP Minero

- disponibilidad de activos;
- horas de detención evitadas;
- cumplimiento preventivo;
- tiempo de OT;
- stock/capital inmovilizado;
- errores de conciliación;
- tiempo de decisión operacional;

Estas métricas son candidatas de instrumentación. Sólo promover a DEMOSTRADO cuando exista fuente canónica, baseline y outcome trazable.
